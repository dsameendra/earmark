Responsive windows
One layout, three window sizes
Schematic frames show where things go as the window changes. Minimum window is 960 × 600. Content never stretches past 1120 pt.
Narrow · 960 × 600 to 1100 pt
Sidebar narrows to its minimum width. The Editor inspector hides behind a toolbar toggle and opens as a solid popover. Home action cards go two across.
Compact · below 800 pt
Sidebar collapses; a toolbar button reveals it as an overlay. Library table drops the Language column, then Speakers. Action cards stack in one column.
Wide · 1440 pt and above
Content is centred with a 1120 pt maximum so transcript lines stay readable (about 70 characters). The Editor inspector stays docked. Full screen adds margin, never wider text.
Dynamic Type and large text: rows grow, nothing clips. Controls keep a 28 pt minimum height; capsule buttons wrap their labels below two lines. Full screen: the sidebar can float over content with the glass material; the player dock stays centred.
