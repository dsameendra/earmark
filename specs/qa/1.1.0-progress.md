## Speech detector and curated ASR checkpoint

- Actual multilingual fixtures exposed an energy-gate defect before Qwen decoding: quiet French and steady-level Japanese were dropped, and German was cut badly. Unsegmented native inference passed, isolating the segmentation problem. Those failed runs are retained in `/tmp/earmark110-qwen-fleurs2.log` and are not counted as acceptance.
- Added an offline Core ML Silero adapter with exact schema checks, per-analysis recurrent state, hysteresis, cancellation and finite/bounded input validation. It never downloads. Four real detector cases retain speech and reject subsequent digital silence.
- General Qwen now loads the required local detector by default. The curated manifest includes all five pinned/hash-checked detector files inside the model's atomic payload. Total size and Apache-2.0/MIT attribution include them. The existing Sinhala detector stays unchanged. Incomplete general installations fail before MLX loading; detector errors no longer silently discard audio.
- Default-path native Qwen smoke plus profile/segmenter checks: 14 tests passed under Xcode/Metal (`/tmp/earmark110-qwen-managed-native2.log`). FLEURS CER: French 5.49%, German 3.37%, Spanish 0%, Japanese 6.67%; correct language tags and no invented word alignment. The first combined run used a wrong English fixture path and is excluded. These are small checkpoint samples, not language-wide quality benchmarks.
- Re-ran all 40 original Sinhala OpenSLR clips after the change: CER 7.63%, WER 35.22%, RTF 0.326, 77.557 seconds; existing CER < 12% passed. Warm-run speed differs from the earlier cold run; no new hardware-tier claim. Log: `/tmp/earmark110-qwen-sinhala-vad-regression.log`.
- Parakeet real file WER 4.55% and buffered stream WER 6.20% passed. Both now require non-empty word alignment as well as timing bounds. The stream test feeds fixture audio in 0.5-second chunks and flushes at end; real-time capture and sustained performance remain release gates. Log: `/tmp/earmark110-parakeet-file-stream.log`.
- ModelStore: 75 tests passed, including the exact combined Qwen manifest and legacy Parakeet vocabulary repair. Features: all 551 tests passed after fixing the mock-composition source guard (`/tmp/earmark110-features-current.log`).
- Direct mock-app inspection verified Add models, Whisper search, empty results and Done, with a screenshot inspected. XCTest daemon startup remains unresolved; this is not a full UI-suite pass.
- General Qwen 0.6B and Parakeet v3 are enabled as experimental buffered engines in the development catalog. Other newly researched checkpoints remain unaccepted until their own native/lifecycle checks pass. No signed 1.1.0 candidate or release has been made.
- Full AudioCapture suite with real detector fixtures: 77 tests passed (`/tmp/earmark110-audio-neural-full.log`). Release-script tests: 27 passed; website validation: zero problems. The new default-path Qwen native run includes profile and segmenter checks; package-wide and signed-app gates remain pending.
